The Ashlyn SMP is a private Minecraft survival multiplayer server with unique gameplay mechanics, lore-driven experiences, and custom-built plugins to create an immersive community experience.

## Our Projects

### [Propaganda](https://github.com/AshlynSMP/Propaganda)
Our core server plugin that powers the Ashlyn SMP experience with:
- **PvP Management** - Configurable combat systems with ceasefire mechanics
- **Custom Lore System** - Immersive storytelling and world-building features
- **Voice Chat Integration** - Enhanced communication with Simple Voice Chat API
- **Radio Towers** - Special interactive structures with unique lore significance
- **Broadcast System** - Server-wide announcements and events
- **Enhanced Chat & Death Mechanics** - Custom player interactions

### [Season 2 Resource Pack](https://github.com/AshlynSMP/RS-S2)
Custom textures, models, and sounds tailored specifically for our server's Season 2, enhancing the visual and audio experience of AshlynSMP.
